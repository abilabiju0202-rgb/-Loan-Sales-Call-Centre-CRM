The Loan Sales & Call Centre CRM is a web-based application developed using Python and Django to streamline customer lead management and loan processing activities.

The system provides separate Admin and Staff portals with role-based access control. Administrators can manage employees, assign customer leads, monitor call performance, manage banks and loan schemes, track loan applications, verify customer documents, and generate reports. Staff members can manage their assigned leads, record customer calls, schedule follow-ups, upload documents, and track loan application progress.

The application also includes bulk lead upload through CSV, daily call targets, performance tracking, and a responsive Mobile Admin Dashboard for convenient access on mobile devices.

Technology Stack: Python, Django, SQLite, HTML5, CSS3, Bootstrap 5, JavaScript, and Chart.js.# -Loan-Sales-Call-Centre-CRM
